# tl;dr

- [dotfiles の管理に uchi を作り始めた話](https://zenn.dev/raki/articles/2026-09-06_uchi) を書いた
- aqua を使うようになって[しばらく経つ](https://zenn.dev/raki/articles/2024-05-16_aqua) のでツールの見直しをした
- [hashicorp/levant](https://github.com/hashicorp/levant) がアーカイブされていることに気が付かなかった
- 自前のタスクでも使っていたがエラーになるまで気が付かなかった
- 使っているツールの棚卸しは大事だなって

# uchi

- [officel/uchi: Dotfiles Literate Configuration CLI tool.](https://github.com/officel/uchi)
- リテレートプログラミング（文芸的プログラミング）はあんまり流行らなかった
- リテレートコンフィギュレーションはこの流れを汲んでいて、ドキュメントから設定を作る感じ（正確ではない）
- dotfiles で管理しているツール類の自分用ドキュメントを書いて設定等も埋める、埋め込まれた設定情報からシェル等で使える設定ファイルを生成する、という流れ
- これを先週から作り始めて、いったん自分で使う bash 向けは形になってきたので、ツールの整理をしてたってワケ

# aqau の整理がてら levant を削除

- 普段から [aqua でツールを管理](https://github.com/officel/dotfiles/tree/68bbf56d3b0ab4e2731f5e9bb4a214c5a90fe87c/aqua) している
- ファイル分割した時も掃除したけど、普段から使ってないツールはもう少し掃除してもいいなって
- 前職は EC2 のオートスケール向けに Packer を使っていたけど、現職は k8s 主体で Packer は使用しておらず、しばらく不要かなって
- 同様に Levant も手打ちはまったくしていなかったので、合わせて管理外にした
- ちなみに `aqua rm packer` しても `aqua.yaml` から消えないので、手で削除が必要なの、うまいやり方ないかしら

# levant はこっそり使用していた

- 削除後はあまり気にしていなかったんだけど、デイリーで処理している個人用タスクでエラーに気がついた
- levant をテンプレートエンジンとして使っている処理があって、エラーになっていた。そして2日間それに気づいていなかった
- エラーを握りつぶす処理が入っていたせい（多少エラーがあっても気にしない処理だったので）
- 使用中のツールの管理ができていなかった。というワケ
- じゃあ元に戻すかってなって本家サイトを確認してみたら、2025年にすでにアーカイブになっていた
- アーカイブ済のツールを戻してエラーを回避するか、別のツールを探すかのニ択で、後者にした

# minijinja-cli も使っていた

- AI に別のツールを探してもらったところ、リストに minijinja-cli があった
- [Rust 向けのテンプレートエンジン minijinja を使い始めたので](https://zenn.dev/raki/articles/2024-09-15_minijinja)
- 別の作業ではこっちを使っていて、なんで統一してないうえに忘れてんだ、ってなった
- たぶん当時の自分は必要なタスクに合わせて最適なツール選びを検討していた最中だったかなと
- Ansible も最近まったく書いてないけど、当時はまだ jinja2 テンプレートが自分にとっては最適だったってことかなと（書きやすいしね）

# というわけで

- levant では定期実行した graphql の処理結果を、テンプレートを元にレポート化していた
- これを minijinja-cli に置き換えてもらった（入力と出力の正解がわかっていることはAIにやらせるのがベスト）
- とりあえずエラーもなくなって完了した

# 雑にまとめ

- 反省すべき点は

  - 個人用だからってろくに確認もしないでツールを削除しない
  - アーカイブされていることに1年も気が付かないほど放置するようなツールを使わない
  - 自分で選んで使っているツールの管理はちゃんとするべき

- 見直した結果

  - 不要なツールの削除手順に自分用ルールができた
  - あまり使っていないツールの見直しができた
  - uchi を作ってドキュメントを管理することで今後はこれらの問題を最小化できる（はず）

- 余談

  - 以前調べた時よりもテンプレート周りが少しだけ賑やか（他のツールを再検討してもいいかも）
  - minijinja-cli 自体も brew 化されたおかげ？か aqua でインストールが可能になっていた（インストールシェルに頼らなくてよくなってた）
  - 定期的な見直しの大事さよ
