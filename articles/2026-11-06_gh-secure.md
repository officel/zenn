# tl;dr

- GitHub のリポジトリを常々セキュアにしたいと考えている
- 正直、何がどこまでできていればセキュアと言えるのか自信はない
- [GitHub Security Lab](https://securitylab.github.com/) の機能拡張が目についたのでお試ししてみた
- [GitHubSecurityLab/gh-secure: A GitHub CLI extension to enable security features on repositories following best practices from GitHub Security Lab.](https://github.com/GitHubSecurityLab/gh-secure)
- とりあえずインストールして（パブリックな）全リポジトリでしゅっとやっておくべきかも

# セキュリティ

- AI 時代にセキュリティは避けて通れない
- ポジションによって担うセキュリティ対策には差があるよね
- GitHub を使うユーザーは各自のリポジトリのセキュリティ対策をするべき

# GitHub Security Lab の extension

- [GitHubSecurityLab/gh-secure](https://github.com/GitHubSecurityLab/gh-secure) が目に入った
- AIに書かせてみようかなと思ってたことをやってた
- 他にもやることはあるような気はするけど、ステップ1とかDay1としてはいいかなって

## インストール

```sh
gh extension install GitHubSecurityLab/gh-secure
```

## 所感

- 楽で便利
- デフォルトをドライランに設定して、適用実行にフラグをつけるほうが個人的には好み（どうでもいい）
- 適用するだけじゃなくてリポジトリのREADMEにあるドキュメントは読んだほうがよさげ
- 元に戻す機能はないっぽいので心配ならバックアップを取りましょう
