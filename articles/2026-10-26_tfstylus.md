# tfstylus is

- terraform を使い出すとディレクトリやファイルがたくさんになる
- コードを書く人やツールによって、同じリソースブロックでも並び順が異なるなど
- アウトカムはないに等しいけど、整えられるのに整えないのは気持ち悪いって同士のためにツールを作ってみた
- 公式記載の大雑把な並び順に加えて、個人的な経験に基づいて読みやすい順になるようにしている
- 全機能をオフにして何もしない、からスタートできる
- `plan` と `apply` で terraform に揃えたので覚えやすい（はず）

# demo

ここに variable を書いたコードがあるじゃろ

```hcl:variable.tf
variable "test" {
  default     = "test001"
  type        = "string"
  description = "テスト"
}
```

これをこうして（`tfstylus plan`）

```patch
variable.tf: rename to variables.tf [file-name/variables] variable.tf contains a variable block and variables.tf does not exist
variable.tf:1:1: variable_order: variable elements should be ordered description, deprecated, sensitive, nullable,ephemeral, const, type, default, validation
diff --git a/variable.tf b/variables.tf
similarity index 66%
rename from variable.tf
rename to variables.tf
--- a/variable.tf
+++ b/variables.tf
@@ -1,6 +1,6 @@
 variable "test" {
+  description = "テスト"
+  type        = "string"
   default     = "test001"
-  type        = "string"
-  description = "テスト"
 }
```

こうじゃ（`tfstylus apply`）

```hcl:variables.tf
variable "test" {
  description = "テスト"
  type        = "string"
  default     = "test001"
}
```

漏れがなければ terraform の公式リソースブロックは全部網羅してるはずなので、ぜひお手元で試してみて欲しいなって。
