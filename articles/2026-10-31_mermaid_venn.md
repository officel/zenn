# 言語化

- 4つの円を持つベン図を mermaid で書いてって渡したら、複合したベン図は書けない、代わりに別のチャートで書きますって言い出した
- [Venn diagrams (v11.12.3+) | Mermaid](https://mermaid.js.org/syntax/venn.html#higher-arity-unions) 3つ以上を受け入れるって書いてある
- よく読めって渡しても書けなかった
- 仕方がないので、画像をコピーして渡して必ず venn ダイアグラムで書くこと例はこう、としてみたら、文字列は読めたもんではないが形にはなった図ができた
- 見やすく文字列を省略してよいとか、使う文字を限定するとか、収まらないだろうところは省略するとか、逐一言語化しないとそりゃ伝わらない
- 下手に省略許可をスキルにするとして欲しくない時も省略しそうだからな。。。
- 言語化って難しい
- AI時代のスキルのひとつにプロンプト化（要は言語化）が要るよねって

# venn diagram on mermaid

- そもそもバグってるってゆうか、出力が一定しない
- 正確には自動レイアウトのせいで崩れたり崩れなかったりする
- 3つの丸には耐えられるけど、4つの丸にテキストを乗せると計算の都度レイアウトが変わってしまう
- mermaid の自動レイアウトは狙った図を書くのに向いてないよね。。。

# 遊びながら学ぶには

- 遊びながら学ぶってのは、夢中で試行錯誤しながら結果が出るまで自らがんばってみるってこと
- 自分で興味を持ったことって、夢中になって調べたり学んだりするよね
- 先のとおり、AI時代には成果への期待を正確に言語化して、プロンプトやコンテキストにする必要がある（言語化能力を磨く必要がある）
- というわけで、AI時代の遊び兼学びには、**言語化力を磨くためのプロンプトを作成する問い** がいいんじゃないかって思ったワケ

# 問題と回答

- 言語化力を磨くための問いには、適切な問題文と回答例が必要だと思う
- AIへのプロンプトはいい加減な文字列を渡してもそれなりの結果が出てしまう（画像生成プロンプト集とかね。同じプロンプトを渡しても毎回違う結果が出るが、人はそれで満足してしまう）
- できる限り同じ結果を返すようにするためには、揺らいでいい部分とそうではない部分を明確にした回答例がないと合否が判定できない
- 問題文にもその説明を含み、面白みがなくてはいけない（同じ問題内容でも、ニ択か四択かマルバツか自由回答かで面白さが違う）
- AIを使う問題は、揺らぎを許容しつつ、最低限守らなければいけない出力結果を毎回生成できる、というものでなければならない
- つまり、**誰が何回実行しても必要な要素を備えた回答を生成することができるプロンプトを作る**、のがAI的頭の体操の問題としておもしろいのではないか

# というわけでね、こういう問題はどうだろう

![ikigai](/images/2026-10-31_1.jpg)

- 前述のリンク先のサイトにある図を mermaid.js で記述した図である
- この出力を得るために3時間くらい使ってしまった。。。（余談）
- それぞれの円の位置は変わっても構わない（自動レイアウトなのでコントロールできない）
- 文字の位置は変わっても構わないが、関係性は変えないこと（必要かつお金は天職である、ことは変えてはいけない）
- A,B,C,D はなくてもよいこととする
- マークダウン埋め込みの mermaid.js でこのような図を生成するためのコードを生成するAI向けプロンプトを書いてください
